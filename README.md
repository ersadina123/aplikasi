# 🌿 Website Informasi Pola Hidup Sehat

Proyek web sederhana yang interaktif dan edukatif untuk memberikan panduan mengenai pola hidup sehat, lengkap dengan kalkulator BMI (Body Mass Index) serta generator tips kesehatan harian.

## 🛠️ Struktur File
Proyek ini dipisahkan menjadi file-file modular agar mudah dikembangkan:
- `index.html` : Berisi kerangka dan struktur elemen halaman web.
- `style.css` : Mengatur tata letak, warna, tipografi, dan desain antarmuka (UI).
- `script.js` : Menangani logika interaktif seperti perhitungan BMI dan acak tips harian.

## ✨ Fitur Utama
1. **Panduan Pilar Kesehatan:** Informasi ringkas seputar nutrisi, hidrasi, olahraga, dan istirahat.
2. **Kalkulator BMI Otomatis:** Membantu pengguna mengetahui status berat badan berdasarkan tinggi dan berat badan mereka.
3. **Tips Sehat Harian:** Tombol interaktif untuk menampilkan saran kesehatan secara acak.

## 🚀 Cara Menjalankan
1. Pastikan keempat file (`index.html`, `style.css`, `script.js`, dan `README.md`) berada di dalam **satu folder yang sama**.
2. Klik dua kali pada file **`index.html`** untuk membukanya secara langsung di browser web favoritmu (Chrome, Firefox, Edge, atau Safari).
